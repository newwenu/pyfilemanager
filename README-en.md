## Attention

Functionality is partially limited due to:

- Uncommitted binary assets (e.g.binary files-everything.exe)

- Features under active development

- Required external dependencies not bundled with source

## Dependencies

requirements.txt or pyproject.toml

## Customized images, please add a folder named "media" in the src directory, or run main.pyw

This will automatically create the folder.
Put the png image files you need in it.
