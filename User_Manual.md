# User Manual

## Step 1

Install dependencies (requires Python interpreter to be installed first, and environment variables configured)

```bash
pip install -r requirements.txt
```

## Step 2

Run the project

```bash
python main.pyw
```

## Step 3

Using the project

- Double-click a file to open it
- Double-click a folder to enter it
- Press "Ctrl+L" to switch languages

Appendix:

Keyboard Shortcuts (default) - for detailed information press F1 to open the help dialog

For Windows users:

- Go back to parent directory: Alt+Left
- Navigate to home: Ctrl+H
- Copy selected files: Ctrl+C
- Cut selected files: Ctrl+X
- Paste files: Ctrl+V
- Delete selected files: Delete
- Select all files: Ctrl+A
- Rename selected item: F2
- Create new folder: Ctrl+N
- Refresh interface: F5
- Show search box: Ctrl+F
- Focus navigation tree: Alt+N
- Focus file list: Alt+F
- Focus address bar: Alt+D
- Toggle modification time column visibility: Alt+X
- Open/close shortcut help dialog: F1

For Linux users:

- Go back to parent directory: Ctrl+Left
- Navigate to home: Ctrl+H
- Copy selected files: Ctrl+C
- Cut selected files: Ctrl+X
- Paste files: Ctrl+V
- Delete selected files: Delete
- Select all files: Ctrl+A
- Rename selected item: F2
- Create new folder: Ctrl+Shift+N
- Refresh interface: F5
- Show search box: Ctrl+Shift+F
- Focus navigation tree: Ctrl+N
- Focus file list: Ctrl+F
- Focus address bar: Ctrl+D
- Toggle modification time column visibility: Ctrl+T
- Open/close shortcut help dialog: F1
